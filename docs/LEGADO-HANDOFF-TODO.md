## 已知网络现象与边界

- xgshort：Mac 返回 403 Cloudflare 挑战页，而测试机返回 200；huadudm／66yy：测试机连接断开、Mac 返回 200；agedm：两端 TLS 握手中断。不能据此判定网站死亡。
- 不加入 CF／验证码绕过、付费／DRM／登录绕过，不分发私有源定义。版权不明、成人或盗版来源不作为合法验收证据。
- 上游证书错误继续加载的行为未照搬；证书错误直接失败。Cookie／Authorization 不扩散到无关媒体域名。
