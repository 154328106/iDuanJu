# i短剧 iOS 1.5 b15 / Android 1.5.15 — 小说界面重构版

本次更新重构了双端小说模块的 **书架 / 书籍搜索 / 书籍详情 / 小说榜单** 四个核心页面，全面对齐短剧 `STVTheme` 视觉体系并精简冗余卡片，同时保留原有 Legado 多源搜索、筛选与阅读功能。

## 本次更新

- **书架**：改为首页同款封面氛围「最近在读」Hero 横幅 + 白色高对比续读按钮；下方「搜书 / 排行榜 / 书源 / 导入」去卡片轻量化；新增「全部 / 在读 / 本地」轻筛选；升级书脊压痕与无图「布面精装」兜底封面。
- **书籍搜索**：返回、搜索框与启用书源计数合入一体化顶栏；全页 0 卡片开放细线列表，精确命中行自然领衔并展示关键字高亮、简介预览与多源聚合角标。
- **书籍详情**：对齐短剧详情架构——全幅封面模糊氛围头图、唯一轻容器三列真实指标带（目录总章 / 可用书源 / 离线已缓）、黑白高对比「开始阅读」与圆形「书架 / 下载」按钮（上滑吸底浮现），简介、目录换源与编号试读章节改为开放细线排版。
- **小说榜单**：移除旧版 86dp 左侧竖栏，采用顶部「书源切换胶囊 + 榜单页签 + 分类胶囊」全宽横栏，搭配 0 卡片 Top 3 三列大封面领奖台与 `#4` 起全宽开放列表。
- **发布流水线**：新增 tag 自动构建发布工作流（`.github/workflows/release-on-tag.yml`），推送 `v*` 标签自动完成双端构建、校验与 Release 发布。

## 验证说明

- Android：本地通过 `:core:test`、`:app:assembleDebug`、`:app:assembleDebugAndroidTest`，CI 自动构建签名 Release APK 并校验签名与 SHA-256。
- iOS：CI 自动构建 Release 未签名 IPA 并校验包结构、版本号与 SHA-256；本轮未在实体 iPhone 上做真机 UI 验收。
